# Food Reviews

A restaurant review site built with Django and Wagtail. Each review has a star rating
from one to five and separate sections for taste, sides, service and an overall
verdict. Content is managed in the Wagtail admin and is available in Finnish and
English.

## Status

In use, with published reviews in the database.

Implemented:

- Front page listing reviews as cards with star rating and photo
- Filtering by location and minimum star rating
- Review pages with taste, sides, service and overall sections
- Photo galleries with captions
- Tags and a tag index page
- Authors as reusable snippets
- Finnish and English versions, Finnish at the root and English under `/en/`

Not implemented:

- Production database. Only SQLite is configured.
- Tests. `blog/tests.py` is the default file generated by Django.
- Proper translations for interface texts. They are written in the templates as
  `{% if is_en %}` checks instead of Django translation files.
- `.gitignore`. The database and uploaded images are committed to the repository.
- `pyproject.toml` in the root is unused Poetry boilerplate.

## Tech

Django 5.2 and Wagtail 7.0, with wagtail-localize for the two languages. Styles are
SCSS compiled by django-sass-processor, which recompiles automatically while the dev
server runs. Requires Python 3.13 or newer.

The review model is in `blog/models.py`. Stars are rendered through a `stars` property
on the page, and the location and rating filters are in `BlogIndexPage.get_context`.

## Running it

```bash
cd mysite
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Site at http://localhost:8000, admin at http://localhost:8000/admin.

The database is included in the repository. To edit content, create an admin account:

```bash
python manage.py createsuperuser
```

## Layout of the code

```
mysite/
  blog/
    models.py           BlogPage, BlogIndexPage, tags, authors, gallery
    templates/blog/     list, single review, tag index
    templatetags/       locale_pageurl for the language switcher
  home/                 front page
  search/               search view
  mysite/
    settings/           base, dev, production
    static/scss/        mysite.scss, the red and yellow theme
  media/                uploaded images
```

## Writing a review

In the admin, go to Pages, then Ruoka-arvostelut, and add a child page of type Blog
Page. Fill in the restaurant, location, product and price, select a star rating and a
date, and write the taste, sides, service and overall sections. Add gallery images at
the bottom and publish.

To create an English version, open the page and select More, then Translate.
